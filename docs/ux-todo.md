# gcopy 交互优化待办

目标: 让用户尽可能方便地获取 / 共享剪贴板数据.

## P0 高价值 (直接影响获取/共享顺手度)

- [x] **1. 接收端"有新内容"提示**
  - 现象: 远端有更新时必须反复按"同步"才知晓, 否则完全无提示.
  - 线索: `frontend/lib/use-window-visible.ts`, `frontend/lib/window-focus.ts` 定义了但无人使用.
  - 建议: 后台轻量轮询远端 index (或 SSE) -> 同步按钮加角标/文案; 聚焦/切回标签页时提示; 桌面端可选"自动应用", Safari/iOS 因需用户手势仅提示.

- [x] **2. 历史记录 -> 发送到云端**
  - 现象: 历史项只能写本机剪贴板或下载, 想再分享给其它设备需"使用"后再按同步.
  - 涉及: `frontend/components/history-item.tsx` (... 菜单只有 使用/Pin/删除).
  - 建议: 每条历史项增加"发送/分享到云端"动作, 直接推送到服务器.

- [ ] **3. 单按钮语义 + 快捷输入优先级提示**
  - 现象: 同一按钮时而拉取时而推送, 方向只体现在日志; 快捷输入非空时静默优先上传其内容而非剪贴板.
  - 涉及: `frontend/components/sync-clipboard.tsx:600-602`.
  - 建议: 按钮状态化文案/图标 (获取新内容 / 发送剪贴板); 快捷输入非空时明确提示"将发送快捷输入内容", 增加"清空"与"把剪贴板贴进来".

- [x] **4. 特殊剪贴板 paste / Safari"再按一次"可视引导**
  - 现象: `waitingForPaste` 仅有日志提示, 无界面; 监听器常驻, 未察觉时会意外截获下一次粘贴. Safari 的 `interrupted-r/w` 同样只有日志.
  - 涉及: `frontend/components/sync-clipboard.tsx:51,309-370`.
  - 已做: 同步按钮切换为"取消等待/请再按一次", 日志区加强提醒; 监听器按需挂载, 支持 Esc 取消并在 20 秒后自动关闭.

## P1 中价值 (反馈与防坑)

- [x] **5. 日志人性化**
  - 现象: LogBox 作为主状态面, 内容偏技术化 (已经是最新/剪切板没有改变/百分比).
  - 建议: 默认一行人类可读状态 (已发送 文字 / 已收到截图 / 已是最新), 详细日志收进可展开区域.

- [x] **6. 复制/使用就地反馈**
  - 现象: 历史项 (尤其文字/截图) 需进 ... 菜单"使用", 成功后只在日志体现; 文字项本体不可点.
  - 涉及: `frontend/components/history-item-text.tsx:30-40`.
  - 建议: 整行可点 + 就地"已复制"反馈 (参考头像菜单复制 token 的实现).

- [ ] **7. 剪贴板权限被拒的补救指引**
  - 现象: `denyRead` 仅一条日志, 而读取权限是本类工具的命门.
  - 涉及: `frontend/components/sync-clipboard.tsx:766-768`.
  - 建议: 一次性帮助提示, 说明如何重新允许.

- [x] **8. 文件同步增强**
  - 现象: 仅单文件; 拖拽即上传无确认; 移动端仍提示"拖拽文件到这里"; 接收端文件静默自动下载.
  - 涉及: `frontend/components/sync-file.tsx:39,73`, `frontend/components/sync-clipboard.tsx:590`.
  - 建议: 多文件, 上传进度就地显示, 按设备切换文案, 接收端改为"下载"动作.

- [ ] **9. 历史列表增强**
  - 现象: 不能全选/清空/搜索; Pin 上限仅日志提示; 保留策略 (20+10) 写死.
  - 建议: 至少加"清空"与更明确的 Pin 限制反馈.

## P2 大工程 (方向性投入)

- [ ] **10. PWA + Web Share Target**
  - 支持安装到桌面, 并从系统分享面板"分享到 gcopy". 最贴合"方便共享", 但涉及 manifest/SW/静态导出缓存策略/后端配合, 成本高.

- [ ] **11. 设备维度**
  - 目前为共享单槽位, 无设备列表/指定发送. 需要改数据模型 (多槽位或订阅式).

## P3 细节

- [ ] **12. 上传超时与重试**: `uploadWithProgress` (`sync-clipboard.tsx:106-150`) 无超时/重试, 弱网只报 "Upload failed".
- [ ] **13. 分享当前剪贴板链接**: 头像菜单"复制链接"目前是登录链接 (`avator.tsx:24-32`); 可做"打开即同步"的内容分享链接 (注意 token 泄露风险).
- [ ] **14. 文案澄清**: `subTitle`"按下按钮剪切板就能在不同设备间同步"未说明"先拉取远端, 无更新再推送本地"的真实逻辑.
